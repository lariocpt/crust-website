Welcome to the Crust documentation. Crust is a Bun-powered shell with first-class pipelines — bash commands, TypeScript lambdas, HTTP verbs, globs, and parallel workers all compose under one `|` / `.pipe()` abstraction.

## Install

<InstallBlock />

The installer puts crust in `~/.crust/`, installs Bun if missing, copies a starter config to `~/.config/crust/init.ts`, and (with sudo) registers `~/.crust/bin/crust` in `/etc/shells`.

## v0.1 at a glance

| | |
|---|---|
| Sources | shell commands, `range(a,b)`, globs (`**/*.ts`), `GET <url>` |
| Transforms | shell stages, `(x => …)` TS lambdas, `POST` / `PUT` / `PATCH` / `DELETE` |
| Sinks | stdout (default), `write(path)`, `dest(dir)`, `stats()` |
| Builtins | `cd`, `export`, `alias`, `source`, `history`, `dotenv`, `test-fixture`, `mock-server`, `time`, `exit`, `help` |
| Configuration | `~/.config/crust/init.ts` — register aliases, `crust.fn(...)` stages, lifecycle hooks |
| One-liner mode | `crust -c '<pipeline>'` from any shell |
